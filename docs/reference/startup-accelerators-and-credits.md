## 5. Application tips (short)

1. **One narrative per company:** Restormel = **governed AI platform**; SOPHIA = **stress-test / showcase**, not the applicant brand unless the form asks for products.
2. **Be specific:** inference + **batch eval**, optional **fine-tuning**, **MCP/docs**—avoid generic “we use AI.”
3. **Match spend to story:** if monthly GPU spend is **0**, say so; explain **credits unlock** first dedicated / fine-tune work.
4. **Track deadlines** in a calendar; duplicate the row if you reapply next quarter.
