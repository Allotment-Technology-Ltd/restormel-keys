# Graph platform — optional enterprise licensing (one-pager)

**Status:** Hypothesis only. **Not** required for Keys core. Publish train remains **`graph-v*`** / **`platform-v*`** per [AGENTS.md](../../AGENTS.md).

## Thesis

`@restormel/graph-core`, `@restormel/ui-graph-svelte`, `@restormel/graph-reasoning-extensions`, `@restormel/state`, and `@restormel/context-packs` form an **observability and explainability** layer for multi-step agent workflows. Some enterprises will pay for **licensed** use, support SLAs, or **private registry** mirrors—not for raw graph rendering alone.

## Packaging ideas

- **Keys / Testing attach** — “Explainability add-on” tier: graph fixtures from Testing runs, memory previews (masked), export bundles.
- **Standalone npm** — AGPL/community vs commercial license (legal review required before promises).

## Defer until

- BYO-GPU guides, Release pack, and Keys **integration contract** tracks have owners and traction.
- Clear buyer: platform engineering vs ML vs security.
