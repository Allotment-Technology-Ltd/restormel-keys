
# Restormel Visual Hierarchy Review

Use this skill to ensure each page has **strong hierarchy** so users can scan and instantly recognize the page type (marketing vs docs vs dashboard) and the current section.

## Visual checks

- **Header hierarchy**: H1 is visually dominant; H2/H3 are clearly subordinate.
- **Section rhythm**: Consistent spacing between sections; no cramped blocks that blur together.
- **Nav vs content**: Navigation reads as chrome; content reads as the primary plane.
- **Contrast + emphasis**: Primary actions stand out; secondary actions don’t compete.
- **Consistency across surfaces**: Docs and dashboard share a recognizable “chrome” pattern.
- **Typography**: Display vs UI font usage is intentional (display for headings, mono for UI/copy where appropriate).

## What to output when used

- **Hierarchy problems** (what currently competes / what’s too subtle)
- **Token-safe adjustments** (font-size/weight/spacing using existing CSS variables)
- **Concrete header pattern** (recommended layout for page title + short subhead)
