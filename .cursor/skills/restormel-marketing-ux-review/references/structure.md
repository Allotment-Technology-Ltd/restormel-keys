
# Restormel Marketing Structure Review

Use this skill when reviewing **public** pages (e.g. `/keys`, `/keys/pricing`, `/keys/docs`) to ensure visitors immediately understand **where they are**, **what this page is for**, and **what to do next**.

## Quick checklist (high signal)

- **Page identity (above the fold)**: Clear H1 that matches nav + URL (e.g. “Docs”, “Pricing”, “Dashboard”).
- **Value proposition**: One sentence explaining *why this exists* (not how).
- **Primary CTA**: Exactly one primary action; secondary action is clearly secondary.
- **Audience framing**: Builder vs end-user BYOK is explicit where relevant.
- **Information scent**: Section headers predict what comes next; no “mystery meat” headings.
- **Consistency**: Terminology matches canonical nouns (Gateway key, provider credential, route, policy).
- **Trust signals**: Security / privacy / “no raw keys logged” message where it reduces drop-off.
- **Wayfinding**: Breadcrumb / page label / nav highlight makes current location obvious.

## What to output when used

- **Top 3 issues** (blocking clarity)
- **Top 3 quick wins** (copy/layout tweaks that are cheap)
- **Proposed H1 + subhead** (one option per page)
- **CTA recommendation** (primary/secondary)
