# Restormel marketing & UX review (three lenses)

Pick the lens that matches the request; run multiple lenses for full-page audits.

## Lens 1 — Structure & messaging

See [references/structure.md](references/structure.md).

High signal: page identity (H1 = nav + URL), value prop, single primary CTA, audience framing (builder vs BYOK), trust signals.

## Lens 2 — Wayfinding & navigation

See [references/wayfinding.md](references/wayfinding.md).

High signal: recoverable collapsed nav, current location (H1 + active nav), keyboard/a11y on toggles, skip links, nav survives loading/error states.

## Lens 3 — Visual hierarchy

See [references/visual-hierarchy.md](references/visual-hierarchy.md).

High signal: H1 dominance, section rhythm, nav vs content plane, token-safe emphasis, consistent chrome across docs/dashboard.

## Combined output format

When running a full review, deliver:

1. **Top 3 blocking issues** (clarity or wayfinding)
2. **Top 3 quick wins**
3. **Proposed H1 + subhead** (one option)
4. **CTA recommendation** (primary/secondary)
5. **Minimal fix** for any blocking UX issue

Pair with `restormel-neu-brutalist-ui` for dashboard chrome and `restormel-accessibility` for a11y depth.
