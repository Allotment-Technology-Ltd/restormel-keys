# `@restormel/graph-reasoning-extensions`

Graph reasoning helpers that depend on **`@restormel/contracts`** (compare, lineage, projection, evaluation, summary, diff) and **`@restormel/graph-core`** (layout, workspace filters).

**Restormel Graph Contract v0** (`GraphData`, canvas DTOs) stays in **`@restormel/graph-core`** — not in this package.

**Public graph UI docs:** [restormel.dev/graph/docs](https://restormel.dev/graph/docs) · [SvelteKit integration](https://restormel.dev/graph/docs/integration/sveltekit).

**Publish train:** git tag **`platform-v*`** (see `.github/workflows/publish-restormel-platform.yml`). Legacy notes: [PUBLISHING.md](./PUBLISHING.md).
