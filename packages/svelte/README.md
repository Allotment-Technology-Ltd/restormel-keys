# @restormel/keys-svelte

> **Deprecated (Phase 7):** Prefer **`@restormel/keys-elements`** or **Keys REST**. **Bugfix-only** until **2026-12-01**, then npm deprecation. See [npm-to-rest-keys.md](../../docs/guides/npm-to-rest-keys.md) and [npm-maintenance-window.md](../../docs/runbooks/npm-maintenance-window.md).

Svelte 5 components for Restormel Keys: `KeyManager`, `ModelSelector`, and `CostEstimator`.

## Install

```bash
pnpm add @restormel/keys @restormel/keys-svelte
```

Import components from `@restormel/keys-svelte` and pass a `createKeys()` instance from `@restormel/keys`. For framework-agnostic UI, use `@restormel/keys-elements` instead.
