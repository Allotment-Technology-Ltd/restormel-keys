# Restormel site (marketing / holding)

Minimal Astro site for **restormel.dev**. Uses brand design tokens from `docs/04-design-and-site.md` (--rm-*).

## Commands

- `pnpm dev` — dev server
- `pnpm build` — static build to `dist/`
- `pnpm preview` — preview production build
