BrutalButton

Neo-brutalist action button. Mono uppercase label, hard 2px ink border, square corners and a hard offset shadow that lifts on hover (translate -2,-2) and presses on active (translate +2,+2). Variants map to brutal-btn-primary, brutal-btn-outline (+ optional brut-fill-*) or brutal-btn-ghost.
