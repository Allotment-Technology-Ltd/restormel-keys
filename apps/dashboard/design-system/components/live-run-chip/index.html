LiveRunChip

Topbar chip that appears only while an ingest run is active in the workspace — it never renders an empty shell. The dot pulses while live; on stall it turns amber, swaps the label to "STALLED" and holds the dot steady (amber + text carry the meaning, no pulse). Links to the run console at /runs/[id].
